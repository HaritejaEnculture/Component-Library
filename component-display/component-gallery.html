EncInputField

Single approved text/input primitive; applies to input, textarea, select where applicable.

Role / Intent: Single approved text/input primitive for forms.

Use when: Text, textarea, or select in Survey Creator, Admin, or forms.

Do NOT use when: Custom-styled search that overrides DS; use enc-input (forbidden — use enc-input-field).

Stable props: class enc-input-field; type, placeholder, disabled; aria-label or associated label.

Size enforcement: Input height is controlled by Enculture density tokens only: --en-density-control-height (comfortable, 48px) and --en-density-compact-control-height (compact, 40px). Product code MUST NOT set custom heights, use Shadcn size props, Tailwind h-*/py-*, or per-input sizing. Search inputs are NOT special — they use the same height as EncInput.

Governance: Placeholder/disabled colors from DS; semantic labels required; no raw colors; height, padding, and radius MUST resolve from Enculture density tokens (see Input size enforcement CANONICAL).

Success states: Valid/unchanged input uses default styling; success feedback (e.g. "Saved") use EncToast (Success) or helper text; error state per form governance (not implied by EncInputField alone).

Do not use for:
  • Data-visualization or analytics filter inputs with custom styling
  • Dashboard-only inputs that bypass DS semantics
  • Without accessible label (aria-label or <label for>)

EncTag

Governed metadata label for status, sentiment, lifecycle, or categorical metadata.

Role / Intent: Non-interactive metadata label. EncTag is a governed badge/chip component, not a decorative element.

Use when: You need a compact label to communicate status (e.g. Completed, Draft), sentiment (e.g. Critical), lifecycle (e.g. Archived), or neutral categories (e.g. Department X) in lists, filters, tables, or cards.

Do NOT use when: As a button or clickable filter; for navigation; for chart legends or data-vis color keys; as the only indicator of action or routing.

Stable props (semantic): class enc-tag; label text (short, 1–2 words in Title/Sentence case; no ALL CAPS, no emojis).

Stable props (EncTag component API): variant (status | sentiment | lifecycle | neutral), tone (success | warning | error | neutral), optional icon and iconPosition (left | right), and inherited density (compact / expanded).

Color / tone variants (DS-owned):

  • tone="success" → --en-success-*. Use for positive outcomes and completed states (e.g. Completed, Delivered).
  • tone="warning" → --en-sentiment-neutral. Use for neutral/warning sentiment that requires attention but is not an error (e.g. At risk, Action needed).
  • tone="error" → --en-error-*. Use for negative or critical sentiment (e.g. Critical, Failed).
  • tone="neutral" → System.EnThemeGray.*. Use for non-sentiment metadata (e.g. Draft, Archived, categories like Department X).

Governance: EncTag is flexible in meaning, not in appearance. Custom colors, shadows, sizes, or feature-specific variants are forbidden. Icon-only EncTag is forbidden; any click behavior must be owned by a parent component (links, filters) and must not be baked into EncTag itself.

Do not use for:
  • Clickable filters or actions (use EncButton or EncIconButton; parent may wrap EncTag inside, but EncTag itself stays non-interactive).
  • Analytics or dashboard chart legends (use data-vis / chart tokens instead of EncTag).
  • Navigation tabs or pills (use the appropriate nav component).
  • Icon-only chips or badges (EncTag must always include a text label).
  • Custom visual styles: brand purple tags, dashboard pastels, gradients, glow, animation, or raw hex/rgb colors.
<EncTag variant="status" tone="success" icon="check" iconPosition="right"> Completed </EncTag> <EncTag variant="sentiment" tone="error" icon="alert-triangle"> Critical </EncTag> <EncTag variant="neutral"> Draft </EncTag>

EncButton (enc-action-primary / enc-action-secondary)

Primary/secondary action button. States: default, hover, focus, disabled. Size variants per DS: Lg, Sm, Mini (not bound in enculture.css; shown: default).

Role / Intent: Primary or secondary action button.

Use when: Main CTA (primary); secondary actions like Cancel, Back (secondary).

Do NOT use when: Navigation link (use <a>); icon-only (use EncIconButton); toggle (use EncToggle). Do not use enc-btn or enc-btn-primary (forbidden).

Stable props: class enc-action-primary or enc-action-secondary; disabled; visible label.

Governance: enc-btn/enc-btn-primary forbidden; focus visible; disabled not focusable; label required.

Destruction warning: For destructive actions (delete, remove, irreversible), use enc-action-secondary and always show confirmation (modal or step) before submit; do not use enc-action-primary for destructive without confirmation.

Success states: After success, use EncToast (Success) or EncTag for status; disabled state for loading; no built-in success visual on the button.

Do not use for:
  • enc-btn or enc-btn-primary (forbidden; use enc-action-primary/secondary only)
  • Status badge or label (use EncTag)
  • Primary destructive action without confirmation flow
  • Dashboard or analytics-only custom buttons that bypass DS
