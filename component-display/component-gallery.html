EncDivider

Visual separation between sections or groups without creating hierarchy.

Role / Intent: Visual separation without creating hierarchy.

Use when: Separating sections, lists, or card content.

Do NOT use when: As a layout container; as a decorative line inside charts or analytics.

Stable props: Class enc-divider only (semantic hook).

Governance: Uses border tokens only; must not be used as a layout container.

Do not use for:
  • Analytics or dashboard chart dividers (use chart/DS rules for data viz)
  • Layout (e.g. flex/grid spacer)
  • Status or action separator (use EncTag or EncButton for actions)

EncInputField

Single approved text/input primitive; applies to input, textarea, select where applicable.

Role / Intent: Single approved text/input primitive for forms.

Use when: Text, textarea, or select in Survey Creator, Admin, or forms.

Do NOT use when: Custom-styled search that overrides DS; use enc-input (forbidden — use enc-input-field).

Stable props: class enc-input-field; type, placeholder, disabled; aria-label or associated label.

Governance: Placeholder/disabled colors from DS; semantic labels required; no raw colors.

Success states: Valid/unchanged input uses default styling; success feedback (e.g. "Saved") use EncToast (Success) or helper text; error state per form governance (not implied by EncInputField alone).

Do not use for:
  • Data-visualization or analytics filter inputs with custom styling
  • Dashboard-only inputs that bypass DS semantics
  • Without accessible label (aria-label or <label for>)

EncButton (enc-action-primary / enc-action-secondary)

Primary/secondary action button. States: default, hover, focus, disabled. Size variants per DS: Lg, Sm, Mini (not bound in enculture.css; shown: default).

Role / Intent: Primary or secondary action button.

Use when: Main CTA (primary); secondary actions like Cancel, Back (secondary).

Do NOT use when: Navigation link (use <a>); icon-only (use EncIconButton); toggle (use EncToggle). Do not use enc-btn or enc-btn-primary (forbidden).

Stable props: class enc-action-primary or enc-action-secondary; disabled; visible label.

Governance: enc-btn/enc-btn-primary forbidden; focus visible; disabled not focusable; label required.

Destruction warning: For destructive actions (delete, remove, irreversible), use enc-action-secondary and always show confirmation (modal or step) before submit; do not use enc-action-primary for destructive without confirmation.

Success states: After success, use EncToast (Success) or EncTag for status; disabled state for loading; no built-in success visual on the button.

Do not use for:
  • enc-btn or enc-btn-primary (forbidden; use enc-action-primary/secondary only)
  • Status badge or label (use EncTag)
  • Primary destructive action without confirmation flow
  • Dashboard or analytics-only custom buttons that bypass DS
<button type="button" class="enc-action-primary">Save</button> <button type="button" class="enc-action-secondary">Cancel</button>

EncIconButton

Icon-only action button (Lucide). Accessible label required. Sizes: Icon.Sm, Icon.Md, Icon.Lg.

Role / Intent: Icon-only action button.

Use when: Add, Edit, Expand, More, Sidebar toggle, list row actions.

Do NOT use when: Primary CTA (use EncButton with label); when label is essential for clarity.

Stable props: class enc-icon-button; aria-label (required); icon from Lucide only.

Governance: Accessible label required (aria-label or sr-only); icon size from DS; Lucide only.

Destruction warning: For delete/remove icon actions, require confirmation (modal or step) before executing; use aria-label that indicates action (e.g. "Delete item").

Success states: After success, use EncToast (Success); no built-in success visual on the icon button.

Do not use for:
  • Without aria-label or sr-only (accessibility violation)
  • Primary submit or main CTA (use enc-action-primary with visible label)
  • Custom icons outside Lucide
  • Dashboard chart controls with custom styling
<button type="button" class="enc-icon-button" aria-label="Add item"><!-- Lucide icon --></button>

EncCard

Primary content surface for grouping related information; owns padding, radius, elevation.

Role / Intent: Primary content surface for grouping related information.

Use when: Dashboards, insights, survey creator, admin panels (grouping content).

Do NOT use when: As a single-action button or clickable container for one action (use EncButton); for modal content without card semantics.

Stable props: class enc-card; content slot.

Governance: Owns padding, radius, elevation; ensure heading hierarchy if card has title; no layout beyond internal stacking.

EncToast

Feedback/notification (Shadcn Toast). Variants: Success, Warning, Error, Info.

Role / Intent: Feedback/notification (toast).

Use when: Success, warning, error, info messages; auto-dismiss 4–6s.

Do NOT use when: Blocking modal; persistent banner; inline validation (use form-level).

Stable props: Variant (Success/Warning/Error/Info); token-only colors; Z-Index 1600.

Governance: Token-only colors; no custom positioning outside DS rules.

Success states: Use Success variant (--en-success-500) for success feedback (e.g. "Saved", "Deleted"); do not imply error for success; auto-dismiss 4–6s.

Do not use for:
  • Analytics or dashboard custom notifications that bypass DS tokens
  • Critical blocking errors (use modal or inline)
  • Status display instead of action feedback
No .enc-* in enculture.css. See EN-AI_Components_Molecules.md EncToast; use production Shadcn Toast with DS tokens.

Component exists but preview not available (no .enc-* semantic in enculture.css).

EncStepper

Linear progress across multi-step flows. States: default, active, completed.

Role / Intent: Linear progress across multi-step flows (survey creation, onboarding, configuration).

Use when: Wizard or step flow; steps indicate progress only.

Do NOT use when: Non-linear navigation; validation gating at component level (handled at flow level).
