### AI Usage & Design System Compliance

All AI-generated UI or code must comply with the Enculture Design System.

- AI tools must use Enculture DS components only.
- Direct usage of Shadcn components in product code is not allowed.
- If a UI requirement is not covered by the Design System, it must be raised as a Design System gap before implementation.
- Design System compliance is mandatory for all pull requests involving UI changes.

If a UI component appears in the product but is not defined in the Enculture Design System, it must be raised as a Design System gap.

Do not implement undocumented components, even if generated by AI tools.
