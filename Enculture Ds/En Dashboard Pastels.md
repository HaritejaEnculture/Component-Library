ENCULTURE — DASHBOARD DATA VISUALIZATION  

FINAL COLOR \& STATE PAGE (EYE-SAFE · AUTHORITATIVE)



STATUS

This page is FINAL.

This page OVERRIDES all previous dashboard color rules.

This page applies to ALL dashboards and analytics.



────────────────────────────────────────

SCOPE

────────────────────────────────────────

\- Dashboards \& analytics ONLY

\- Charts, graphs, heatmaps, KPI visuals

\- Presentation layer ONLY

\- Backend / API data MUST NOT change



────────────────────────────────────────

ABSOLUTE RULES

────────────────────────────────────────

\- DO NOT modify data values

\- DO NOT store colors in API responses

\- DO NOT use brand colors

\- DO NOT use system error / form colors

\- DO NOT use hex, rgb, hsl

\- All chart colors resolve from THIS PAGE only



EYE-SAFETY RULE

\- All charts MUST use shades ≥ 400

\- HEATMAPS ONLY may use shades down to 200

\- No other exceptions allowed



────────────────────────────────────────

PASTEL FAMILIES (APPROVED)

────────────────────────────────────────

\- Violet / Periwinkle → Neutral comparison, trends

\- Green               → Positive / success

\- Yellow              → In-progress / transitional

\- Coral (Red pastel)  → Risk / negative



────────────────────────────────────────

STATUS COLOR MAPPING (MANDATORY)

────────────────────────────────────────

Completed     → Green 500

In Progress   → Yellow 400

Pending       → Coral 500



No substitutions.

No lighter shades allowed.



────────────────────────────────────────

DEFAULT PASTEL SEQUENCE (NON-HEATMAP)

────────────────────────────────────────

1 → Violet 400  

2 → Violet 500  

3 → Violet 600  

4 → Green 500   (only when success is meaningful)  

5 → Coral 500   (only when risk is meaningful)  



Rules:

\- Always start with Violet

\- Escalate within SAME family only

\- NEVER use <400 outside heatmaps



────────────────────────────────────────

CHART TYPE RULES

────────────────────────────────────────



LINE / AREA CHARTS

\- Line stroke  → Violet 600

\- Area fill    → Violet 400 / 500

\- Data points  → Violet 600



Use Green or Coral ONLY if metric explicitly represents success or risk.



BAR / COLUMN CHARTS

\- Default bars     → Violet 500

\- Secondary bars   → Violet 600

\- Success bars     → Green 500

\- Risk bars        → Coral 500



PIE / DONUT CHARTS

\- Default slices   → Violet 400 → 500 → 600

\- Success slice   → Green 500

\- Risk slice      → Coral 500



Color MUST NOT be derived from value alone.



────────────────────────────────────────

HEATMAPS (ONLY PLACE <400 IS ALLOWED)

────────────────────────────────────────



NPS HEATMAP — 3 TIER

Detractor → Coral 400

Passive   → Violet 300

Promoter  → Green 400



Rules:

\- Exactly 3 colors

\- Shades allowed: 300–500

\- Labels required



NPS HEATMAP — 5 TIER

1 → Coral 500   (Strong Detractor)

2 → Coral 400   (Detractor)

3 → Violet 300  (Neutral)

4 → Green 400   (Promoter)

5 → Green 500   (Strong Promoter)



Rules:

\- Exactly 5 fixed buckets

\- Shades allowed: 300–500

\- No interpolation



NON-NPS HEATMAPS

\- Use ONE family only (recommended: Violet)

\- Scale: 200 → 400 → 600

\- Do NOT mix families



────────────────────────────────────────

TEXT \& ACCESSIBILITY

────────────────────────────────────────

\- Text MUST NEVER be pastel

\- Text on pastel backgrounds:

&nbsp; - Shade 200–300 (heatmaps only) → Text.Primary

&nbsp; - Shade 400–600 → Text.OnPrimary



Color is NEVER the only signal.

Labels or values are REQUIRED.
